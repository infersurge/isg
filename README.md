# InferSurge ISG

**Remote Computer Use for AI Agents** — 让 AI 助手安全地使用你的真实计算机。

- 产品：<https://infersurge.com>
- 控制台：<https://app.infersurge.com>

## 这个仓库是做什么的

这是 InferSurge 的**公开反馈与社区交流渠道**：

| 想做什么 | 去哪里 |
|---|---|
| 报告 BUG | [提交 ISSUE](https://github.com/infersurge/isg/issues/new/choose) |
| 提出功能建议 | [提交 ISSUE](https://github.com/infersurge/isg/issues/new/choose) |
| 使用交流 / 提问 / 场景讨论 | [Discussions](https://github.com/infersurge/isg/discussions) |

**本仓库不托管源代码。** 我们在此收集反馈、公开 roadmap 讨论与版本说明；
产品实现不在 GitHub 上。请不要在此提交 Pull Request——我们会看不到对应代码而无法处理。

## 提 ISSUE 前请附上

为了让问题可复现，请尽量提供：

- 客户端（Claude / ChatGPT / 其他 MCP 客户端）与版本
- 被控端系统（Windows / macOS / Linux）与版本
- `isg version` 输出
- 复现步骤与实际/期望行为

> ⚠️ **请勿在 ISSUE 中粘贴 token、凭据、IP、设备标识或任何敏感数据。**
> 公开 ISSUE 任何人可见。如涉及敏感信息，请先在控制台轮换相关凭据，
> 并在 ISSUE 中只描述现象。

## 安全漏洞

**请不要在公开 ISSUE 中披露安全漏洞。** 请通过 <security@infersurge.com> 私下报告，
我们会在修复后公开致谢。
